### What I Build

Projects engineered for local execution, low latency, and zero dependency on recurring cloud SaaS tools.

#### 1. [CLIPGO 6.0](https://github.com/Lanciuy/CLIPGO) &mdash; Local 9:16 Video Factory
Converts horizontal podcasts and streams into vertical viral shorts entirely on local GPU hardware.
- **Computer Vision**: OpenCV YuNet face detection at 128 FPS with smooth Bezier camera pan.
- **Subtitles**: Hardware LibASS kinetic karaoke typography rendered directly into frames.
- **Audio & Stealth**: Silero VAD silence trimming, automatic BGM ducking, sanitized MP42 container flags.
- **Speed**: Full 60-second 1080x1920 export in ~12 seconds via NVIDIA NVENC.

#### 2. [BONSNAP](https://github.com/Lanciuy/BONSNAP) &mdash; Receipt Vision & Expense Agent
- Multimodal receipt parsing using Gemini Vision and Groq Llama 3.
- Fast OCR extraction, merchant classification, and spending breakdown.
- Built on Clean Architecture with local offline caching.

#### 3. [CLINK](https://github.com/Lanciuy/CLINK) &mdash; Stealth Downloader & Upscaler
- 4-tier media extraction engine backed by Playwright Stealth and yt-dlp.
- Real-ESRGAN x4 AI super-resolution integration for high-definition frame restoration.

#### 4. [WARNET_SYSTEM](https://github.com/Lanciuy/WARNET_SYSTEM) &mdash; NetCafe & Esports Management
- High-performance billing and kiosk monorepo built with Fastify, Socket.io, Node:SQLite, and Electron.
- Real-time client lockouts, member card tap, and live operator telemetry.

#### 5. [Memory MCP](https://github.com/Lanciuy) &mdash; Cognitive Graph for AI Agents
- Model Context Protocol server delivering persistent graph memory and architecture indexing to agentic LLMs.
